**Settings → Job boards** (Super Admins, Accounts Managers).

1. Find the board and click **Connect**.
2. Enter the credentials the board gives you. An API key or access token is required; credentials are stored encrypted.
3. Optionally add a **Webhook secret**, and register the webhook address shown on the page in the board's developer console, so applications flow back into ZorHire.
4. Click **Save credentials**.

Then use **Publish to boards** on any job. **Disconnect** stops managing existing postings from ZorHire.

The boards available depend on what's enabled for your company. For free boards without an API, use **Post free** on the job.
