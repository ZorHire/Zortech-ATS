- Click **Help** in the top bar on any page to ask **Aruna**, ZorHire's help assistant. She knows these help topics and tells you where to click. She can't see your company's data or make changes for you, and she's an AI, so check the linked guide when it matters.
- Browse every topic under **Help** in the menu, or search them. Aruna is also on the Help page.
- Rate an answer with the thumbs, so we can improve the help.
- For problems the help doesn't cover, ask your company admin, or contact ZorTech support.
