You need the **ZorHire Assistant** Chrome extension or the ZorHire Windows app.

- On a **LinkedIn profile** or a **Naukri Resdex/Recruit** page, click the **Save to ZorHire** button on the page.
- On any other site (Indeed, foundit, GitHub, company pages), click the extension icon → **Save this page to ZorHire**. In the Windows app use the **Assistant** panel or right-click → **Save this page to ZorHire**.

ZorHire reads the page and shows the details for you to check. You can pick a job (the person joins it as **Sourced**), attach a resume, and save.

**Duplicates:** before saving it shows anyone already in ZorHire with the same profile link, email, phone or name and company, who added them and which jobs they're in. You can add the new details to that candidate, or save a new candidate anyway.

It never clicks "view phone/email" on Naukri (that uses paid credits) and only downloads a resume when you tick the box.
