ZorHire for Windows shows ZorHire in its own window, with tabs for LinkedIn, Recruiter Lite and Naukri (the **+** button) and the ZorHire Assistant built in, so you don't need Chrome or the extension.

- **Download:** in the browser, the **LinkedIn agent** page shows **Download ZorHire for Windows**. If Windows says "Windows protected your PC", choose **More info → Run anyway**.
- **Connects by itself:** once you're signed in to ZorHire, the app connects the assistant; there's no code to paste.
- **Assistant panel:** status, LinkedIn account, the **LinkedIn agent running** switch, working hours, **Save this page to ZorHire** and **Run now**.
- **Desktop alerts** for new assignments, interviews and pipeline moves; the bell and taskbar show the unread count.
- **Drop resumes** anywhere in ZorHire to add candidates.
- Closing the window keeps it running in the tray, so alerts and the agent continue. It updates itself.

"Sign in with Google" doesn't work on some sites inside the app; use the site's email sign-in instead.
